# 🔄 SwapHub – Item Exchange Platform

## 📌 Project Description
SwapHub is a frontend web application that allows users to exchange items using a barter system (no money involved). Users can post items and request exchanges with others.

---

## 🚀 Features
- 🏠 View all items in card layout
- ➕ Post new items with details and image
- 🔍 View item details
- 🔁 Request item swaps
- 📋 Track swap requests
- 💾 Data stored using LocalStorage

---

## 🛠 Tech Stack
- HTML5
- CSS3 (Flexbox / Grid)
- JavaScript (DOM, Events, LocalStorage)

---

## 📂 Pages
- Home Page
- Post Item Page
- Item Details Page
- My Requests Page
